# LLM-SKILL Supplement

This folder documents the LLM-dependent steps used in the SwimComposer data preparation pipeline. It is provided to support reproducibility for the manuscript statement that fixed prompts, output schemas, and validation scripts are included in the supplemental material.

## Scope

The LLM is used only in two commentary-processing steps:

1. **Name normalization**: map athlete mentions in timestamped commentary segments to official athlete names from the official race roster.
2. **Insight extraction**: classify normalized commentary segments into predefined insight categories and produce short structured summaries.

The LLM is not used as a factual source. Athlete names, lanes, ranks, countries, and race metadata are grounded in the official metadata snapshot generated by the official-data pipeline.

## Folder Contents

- `SKILL.md`: a compact operational description of the two LLM steps.
- `prompts/`: fixed system prompts used for the two LLM calls.
- `schemas/`: JSON schemas for raw LLM responses and pipeline artifacts.
- `taxonomy/insight_taxonomy.json`: the fixed insight category taxonomy.
- `scripts/validate_llm_outputs.py`: standalone validation script for normalized names and extracted insights.

## How This Connects to the Pipeline

The supplemental data pipeline script `audio_processing_pipeline.py` implements the same two stages:

```bash
python3 audio_processing_pipeline.py normalize-names \
  --transcript transcript.json \
  --snapshot official_metadata.json \
  --output normalized_transcript.json

python3 audio_processing_pipeline.py extract-insights \
  --normalized-transcript normalized_transcript.json \
  --snapshot official_metadata.json \
  --output insight.json
```

The resulting `insight.json` can be used by the SwimComposer frontend as the structured insight/commentary layer.

## Validation

Run validation after the LLM steps:

```bash
python3 LLM-SKILL/scripts/validate_llm_outputs.py \
  --official-snapshot official_metadata.json \
  --normalized-transcript normalized_transcript.json \
  --insights insight.json \
  --taxonomy LLM-SKILL/taxonomy/insight_taxonomy.json
```

The validator checks that normalized athlete names are present in the official roster, that extracted insights use only predefined categories, and that athlete references in insights can be resolved to official roster entries.

## Related Official Metadata Skill

The official metadata collection stage is documented separately in `official_metadata_collecting/`. That skill may use an LLM agent for compact race-name parsing and retrieval orchestration, but factual values are collected from official sources only. The reviewer-facing LLM reproducibility materials in this folder focus on the two LLM calls explicitly used for commentary processing.
